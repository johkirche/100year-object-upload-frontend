# Video Thumbnails

This directory contains thumbnail images for videos displayed on the home page.

## Required Files:
- `geschichte-thumbnail.jpg` - Thumbnail for the church history video
- `anleitung-thumbnail.jpg` - Thumbnail for the upload tutorial video

## Recommended specifications:
- Format: JPEG or PNG
- Dimensions: 400x300 pixels (4:3 aspect ratio)
- File size: < 100KB for optimal loading

## Usage:
These thumbnails are displayed as preview images for the video cards on the home page. When users click on a card, a dialog opens with the actual video player.
