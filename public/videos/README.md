# Videos Directory

This directory contains video files displayed on the home page.

## Required Files:
- `geschichte.mp4` - Church history video
- `anleitung.mp4` - Upload tutorial video

## Recommended specifications:
- Format: MP4 (H.264 codec)
- Resolution: 1920x1080 (Full HD) or 1280x720 (HD)
- Bitrate: 2-5 Mbps for good quality/size balance
- Duration: 2-5 minutes recommended

## Usage:
These videos are played in a modal dialog when users click on the corresponding video cards on the home page.
